How to use it

Read top to bottom. Get stuck on purpose.

Start with Start Here. It explains how the colored boxes work and sets the mindset. Each chapter builds on the ones before it, and each one has an easy practice problem and a harder one with hints.

One rule before you start: when a problem gets hard, sit in the stuck for a minute before you peek at the answer. That discomfort is the part doing the work.
