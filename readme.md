# Calculus 2 From Zero

**You think you're F.\*ked at calculus. You're not.**

A free, start-from-zero guide to Calculus 2, with all the Calc 1 you need built in.

Every chapter starts with why the idea exists and what it's for, before any formula. Then worked examples, a box of the wrong ideas that wreck people, three practice problems with hints, a five-problem workout, and answers at the end. Diagrams where they help, and a Professor Leonard lecture to pair with each one.

🌐 **Website:** [calculus.shriyash.dev](https://calculus.shriyash.dev)
📄 **PDF:** [`calculus-2-from-zero.pdf`](./calculus-2-from-zero.pdf)

## What's inside

A start-here page plus 19 chapters, built to be read in order:

| Part                                        | Chapters                                                                                                             |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Getting Started**                         | Start Here: how to use this book, and why getting stuck is the point                                                 |
| **Calculus 1: The Foundation**              | Limits & Continuity · Derivatives · Applications of Derivatives · Integrals & the FTC                                |
| **Calculus 2: Techniques of Integration**   | Integration by Parts · Trigonometric Integrals · Trigonometric Substitution · Partial Fractions · Improper Integrals |
| **Calculus 2: Applications of Integration** | Area Between Curves · Volumes of Revolution · Arc Length & Surface Area · Work                                       |
| **Calculus 2: Sequences & Series**          | Sequences · Series & the Divergence Test · Integral Test, p-Series & Comparison · Alternating, Ratio & Root Tests    |
| **Calculus 2: Power Series & Taylor**       | Power Series · Taylor & Maclaurin Series                                                                             |

Skipping ahead to series? You need limits from Calc 1, plus Partial Fractions and Improper Integrals: telescoping series are built on partial fractions, and the p-series rule comes straight from improper integrals.

## About this repo

This is the book's website: plain HTML and CSS, no framework, no build step.

```
.
├── index.html                 # the whole site
├── calculus-2-from-zero.pdf   # the book
└── vercel.json                # serves the PDF inline + caching
```

**Run it locally:** open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server
```
